Cross-Application Attack Chains
Multi-stage exploitation paths across service boundaries · MITRE ATLAS aligned
CRITICAL AC-001 — Content Mod → Finance Data Exfiltration
MITRE ATLAS: AML.T0054 · Apps: content-mod → finance · Shared LLM context bleed
Steps
1Inject system prompt override via content submission (PI-001)
2Poisoned context propagates via shared LLM API key/session
3Finance app executes injected instructions, leaks financial data (EX-003)
Remediation: Isolate LLM API keys per service. Use separate system prompt contexts. Implement output scanning at each service boundary.
CRITICAL AC-002 — Support Chatbot → Admin Credential Theft
MITRE ATLAS: AML.T0054.002 · Indirect Prompt Injection · Apps: support → external
Steps
1Submit crafted customer message with indirect injection payload (PI-006)
2LLM processes malicious context without sanitization
3Admin credentials extracted from system prompt (EX-005)
Remediation: Sanitize all external data before LLM context inclusion. Never store credentials in system prompts. Filter credential patterns in output.
HIGH AC-003 — Cross-App Payload Propagation
MITRE ATLAS: AML.T0054.003 · Multi-Stage Injection · Apps: all 3 services compromised
Steps
1Plant cross-app propagation payload in content-mod (PI-010)
2Payload embedded in shared LLM context window
3Finance service executes cross-app instructions
4Support service also compromised via same shared context
Remediation: Implement context isolation per service. Use session-scoped LLM contexts. Deploy output classification to detect injected instructions.
